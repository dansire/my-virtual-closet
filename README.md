# 👗 My Virtual Closet

Aplicación web para organizar tu armario, crear outfits y planificar tu vestuario.

> 🚧 Proyecto en desarrollo. Actualmente en la Fase 1: configuración inicial.

## Tecnologías

- React + Vite
- JavaScript (ES6+)
- CSS3
- React Router, Recharts, date-fns, Lucide React
- Vitest + React Testing Library

## Instalación y ejecución local

```bash
git clone https://github.com/dansire/my-virtual-closet.git
cd my-virtual-closet
npm install
npm run dev
```

Abre `http://localhost:5173/my-virtual-closet/` en tu navegador.

## Pruebas

```bash
npm test
```
